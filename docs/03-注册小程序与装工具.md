# 3. 注册小程序与装工具

> 这一节从零开始：拿到 AppID、装上工具、第一次跑起来、把云开发环境开好。四步走完，你就有了一个能开发、能上云的工作台。

## 3.1 注册：从邮箱到 AppID

**入口**：微信公众平台 `mp.weixin.qq.com` → 立即注册 → 小程序。

**材料**：一个没注册过公众号/小程序的邮箱、身份证、手机号。个人主体免费，全程线上。

**主体类型**在注册时就选了，它决定你能做什么（详表见第 9 节）：

- 个人主体：免费，类目少——**不能做**支付、社交（用户发内容）、AI 生成内容（深度合成类目）；
- 企业主体：注册也免费，但要微信认证（300 元/年）才能解锁完整类目和支付。

**注册完第一件事**：设置 → 基本设置 → 找到 **AppID**（`wx` 开头一串）。

（大白话：AppID 就是小程序的身份证号。装工具要用它、云开发要绑它、后台所有配置都认它。注册 10 分钟，它决定你后面所有事的上限——个人主体能做什么、不能做什么，最好在写第一行代码之前就搞清楚。）

## 3.2 装工具：下载哪个、界面长什么样

**下载哪个版本**：官方下载页有三个版本——**稳定版、预发布版、开发版**。选**稳定版**，除非你需要某个只在测试版里的新特性。

**导入项目**：打开工具 → 「+」→ 导入 → 选项目根目录（里面必须有 `project.config.json`）→ 填 AppID。

还没有代码？选「新建项目」，模板选 JavaScript 基础模板，先跑起来再说。

**界面四大块**：

| 区域 | 干嘛的 | 一句话 |
|---|---|---|
| 模拟器（左） | 实时预览页面 | 一个假手机，改完代码自动刷 |
| 编辑器（中） | 写代码 | 它 |
| 调试器（下） | Console / Network / AppData / Storage | 排查问题的全部家当（第 8 节细讲） |
| 工具栏（上） | 编译 / 预览 / 真机调试 / 上传 | 四个按钮区别见下 |

（大白话：**编译**=模拟器里刷新；**预览**=生成二维码自己手机上看，下班失效；**真机调试**=手机上跑、电脑上看 log，查 bug 用；**上传**=把代码交到后台，做体验版或提审。）

## 3.3 第一次跑起来：几个高频报错

| 现象 | 原因 | 解法 |
|---|---|---|
| 提示 AppID 无效或功能受限 | 用了测试号（`touristappid`） | 换成真实 AppID——云开发、真机预览都要求真实 AppID |
| `app.json` 内容错误 / 页面不存在 | pages 里的路径和实际文件对不上 | 核对路径大小写、文件是否齐全（每个页面要 js/ts + wxml + json） |
| 提示基础库版本问题 | 项目的 libVersion 和本地不一致 | 详情 → 本地设置 → 调试基础库，选一个稳定版本 |
| 模拟器能请求接口，真机不行 | 请求的域名不在合法域名名单里 | 开发期可在本地设置里关掉"校验合法域名"；**上线前必须配域名**（第 9 节） |
| 编译通过但白屏 | 页面脚本运行时报错 | 看调试器 Console，**红字第一行就是病根** |

（大白话：白屏不可怕，九成问题 Console 第一行红字就写着。先看报错再猜，别反过来。）

## 3.4 开通云开发环境

**什么时候需要**：想用云函数、云数据库、云存储，或想接 AI 能力（文本生成、图像生成走云开发的扩展）。

**怎么开**：工具栏点「云开发」→ 开通 → 建环境。建的时候会让你起环境名、选计费方案——**有免费额度档**，起步选它。

**环境 ID 用在哪**：两处——前端 `wx.cloud.init({ env: '你的环境ID' })`、云函数的配置。它相当于你云端小服务器的门牌号。

（大白话：云开发环境 = 腾讯帮你管好的云端小服务器，数据库、存储、云函数都装在里面，不用买服务器、不用配 HTTPS、不用备案。代价是它的计费规则你得花半小时看懂——免费额度覆盖开发和演示期没问题，上线后按调用量算，先看第 2 节的账。）

**一个容易漏的点**：环境建好后，**开发者工具里要确认登录态**（右上角头像），云开发面板才能正常打开。第一次进不去八成是没登录或者 AppID 是测试号。

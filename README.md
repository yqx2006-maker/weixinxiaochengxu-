## 写作规则（已定，不再改）

1. 每节先对要点，确认后才动笔；
2. 首要标准是**读完就懂**：正文写得直白就不加注释；只有确实抽象的概念，才用括号补一句大白话；
3. 所有数字必须核实（git 历史 / 工作日志），不用比赛材料的美化口径；
4. 不用排比句、不用金句、不自我标榜；
5. 保留纠错痕迹：判断错了的地方，写明错在哪、改成了什么。

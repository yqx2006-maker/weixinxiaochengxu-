# 第一册 · 从零到跑通

这一册讲**具体怎么做**：选什么技术、五天怎么分配、AI 怎么接、云开发怎么部署。

读者对象是「要在有限时间里做出一个完整可体验小程序」的人。内容基于一个真实项目（5 个工作日、5 Tab × 14 页面、3 云函数），但不复制其业务内容——你换成自己的主题，流程是一样的。

## 先看这一条

如果你时间很紧，只读 [03 · AI 链路接入](03-AI链路接入.md) 里的**「降级策略」**一节。

那个项目里最有价值的技术决策不是"接了 AI"，而是**假设 AI 一定会挂，然后让产品在挂掉时依然走完**。这个决定是在真正被限流一次之后才做出来的——在那之前，AI 失败意味着用户看到一片空白。

## 一条读法建议

**不要通读。** 这份手册的价值在于**被查阅**，不在于被背下来。

真正该记住的是这四条**跨主题的元规律**（它们在第 8 篇里有详细展开）：

1. **凡是"看起来成功了"的地方，都值得再验一次**——生成成功但保存失败、函数正常返回但其实是错误、命令执行成功但没有输出。
2. **凡是"重建一个对象"的代码，都要过一遍全部字段**——丢字段的 bug 有一半出自这里。
3. **凡是"判断是否存在"的逻辑，都要确认判断依据没有被前置步骤改写**——按需补全静默失效就是这么来的。
4. **凡是"平台能力边界"的问题，必须查当前官方文档**——不能靠推断，因为不同平台的差异极大，而且规则会变。
